Godot includes a dedicated 2D renderer and 2D physics engine, as well as 2D-specific features like tilemaps, particles, and animation systems. This section covers most 2D-specific topics in Godot.

For 2D topics not covered in this section, see also [2D skeletons](https://docs.godotengine.org/en/stable/tutorials/animation/2d_skeletons.html#doc-2d-skeletons) and [2D navigation overview](https://docs.godotengine.org/en/stable/tutorials/navigation/navigation_introduction_2d.html#doc-navigation-overview-2d). For using physics in 2D, see [Physics](https://docs.godotengine.org/en/stable/tutorials/physics/index.html#doc-physics-index). There is also a step-by-step tutorial on creating a 2D game in [Your first 2D game](https://docs.godotengine.org/en/stable/getting_started/first_2d_game/index.html#doc-your-first-2d-game).
