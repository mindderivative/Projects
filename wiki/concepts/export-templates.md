# Export Templates

## Definition
Export templates are custom builds of the Godot engine that have certain features disabled. They are created using the engine compilation configuration editor and build profiles to reduce the binary size of the engine.

## Key Characteristics
- Custom builds with features disabled
- Created using the engine compilation configuration editor
- Reduced binary size

## Applications
- Reducing binary size for specific use cases
- Optimizing engine performance for targeted scenarios
- Customizing the Godot engine for specific projects
