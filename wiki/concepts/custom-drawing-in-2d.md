## Description
The Godot Engine's script editor provides syntax highlighting for GDScript and JSON files. This feature allows developers to easily distinguish between different elements of their code, such as keywords, variables, and strings. The script editor also serves as an offline class reference viewer, which can be accessed in several ways as described in the [Integrated class reference](https://docs.godotengine.org/en/stable/getting_started/introduction/first_look_at_the_editor.html#doc-intro-to-the-editor-interface-integrated-class-reference). This makes it easier for developers to reference and learn about available classes and methods while working on their projects.
