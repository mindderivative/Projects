# Android Editor

## Definition
The Android editor is a port of the Godot editor that allows developers to use the editor on Android devices to create, develop, and export 2D and 3D projects.

## Key Characteristics
- Port of Godot editor for Android devices
- Allows developers to create, develop, and export 2D and 3D projects on Android devices

## Applications
- Developers can use the editor on their Android devices for project creation and development
- Allows for mobile development and collaboration on the go
