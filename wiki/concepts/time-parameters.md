# time parameters

## Definition
Time parameters are settings in a particle system that control the behavior of the particles over time.

## Key Characteristics
- Lifetime
- One-shot
- Preprocess
- Speed scale
- Explosiveness
- Randomness

## Applications
Time parameters allow for greater control over the visual effects created by particle systems, making it easier to create animations and effects with specific timing and behaviors.
