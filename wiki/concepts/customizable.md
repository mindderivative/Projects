# Customizable

## Definition
The ability to modify the Godot editor interface according to user preferences.

## Key Characteristics
- Movable docks
- Resizable panels
- Ability to save and load dock configurations

## Applications
Customizable feature allows users to tailor the Godot editor interface to their specific needs and preferences, improving productivity and efficiency.
