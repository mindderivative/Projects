## Description
External text editors can be used by developers to write and edit code separately from the Godot editor. They can provide a more comfortable coding environment, support for multiple programming languages, and integration with other development tools. One feature provided by external text editors is code completion, which suggests and auto-completes code snippets based on the context and available functions, variables, and classes.
