# Texture Size

## Definition
Texture size refers to the dimensions of a texture map used in 3D rendering.

## Key Characteristics
- Represents the width and height of a texture map
- Limited by hardware capabilities in some cases

## Applications
- Determines the level of detail in 3D models
- Influences rendering performance
