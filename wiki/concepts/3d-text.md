# 3D Text

## Basic Information
type: concept
sources: [[sources/3d-text_2316fe|3d-text_2316fe]]
definition: 3D text refers to the display of text in a 3D scene in Godot. It can be achieved using the Label3D node or the TextMesh resource for a MeshInstance3D node. Both options have their advantages and limitations.

## Description
3D text in Godot can be used to create text overlays in 3D scenes, add text to 3D GUI elements, and display text in 3D games. It can be achieved using the Label3D node or the TextMesh resource for a MeshInstance3D node. Both options have their advantages and limitations. For example, using a Label3D node is easier to set up but may have limited customization options, while using a TextMesh resource allows for more advanced text rendering but requires more complex setup.
