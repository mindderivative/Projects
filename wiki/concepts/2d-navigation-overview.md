## Description
The 2D navigation overview provides an introduction to navigation in 2D games and covers the basics of navigation in 2D. This guide also provides information on how to implement navigation in 2D games. Navigating the 3D environment is important to adjust the viewpoint or angle while viewing a scene. Godot provides various navigation controls, including orbiting, panning, and zooming, which can be customized in the Editor Settings. These navigation controls help users to better understand and interact with the 3D scene they are working on.
