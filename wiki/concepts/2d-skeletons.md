# 2D Skeletons

## Definition
2D skeletons are a technique used in the Godot game engine for creating and animating 2D characters and entities. They involve the definition of a skeleton hierarchy and the attachment of 2D meshes and animations to the skeletal structure.

## Key Characteristics
- Definition of a skeleton hierarchy
- Attachment of 2D meshes and animations to the skeletal structure

## Applications
2D skeletons are used in 2D character and entity animation in the Godot game engine.
