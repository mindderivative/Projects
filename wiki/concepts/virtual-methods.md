# Virtual Methods

## Definition
Virtual methods are methods in Godot classes that can be overridden by subclasses. They are used to provide custom behavior in derived classes.

## Key Characteristics
- Methods labeled as "virtual" in the Godot documentation are intended to be overridden by scripts.
- Virtual methods provide the ability to customize the behavior of a class in a derived class.

## Applications
- Virtual methods are commonly used in object-oriented programming to implement polymorphism.
- They allow for the creation of flexible and reusable code by providing a way to customize the behavior of a class.
