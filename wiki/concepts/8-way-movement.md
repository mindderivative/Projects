# 2D Movement

## Definition

2D movement refers to the movement of characters and objects in a 2D game or application. This tutorial demonstrates how to create 2D movement in Godot using different methods such as 8-way movement, rotation + movement, rotation + movement (mouse), and click-and-move.

## Key Characteristics

- Movement of characters and objects in a 2D game or application
- Different methods such as 8-way movement, rotation + movement, rotation + movement (mouse), and click-and-move

## Applications

- Games with characters that need to move around in a 2D environment
- Applications with objects that need to be controlled or moved in a 2D space
