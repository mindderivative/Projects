# USE_SCENE (META ONLY)

## Definition
USE_SCENE (META ONLY) is a permission required by the Godot XR editor to enable and access the scene APIs when running an XR project on Meta Quest devices.

## Key Characteristics
- Required permission for XR projects on Meta Quest devices
- Enables access to scene APIs

## Applications
- Enabling and accessing scene APIs for XR projects on Meta Quest devices
