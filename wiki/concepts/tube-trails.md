# Tube Trails

## Definition
Tube Trails is a technique in Godot game engine to create particle trails that use cylindrical meshes. It involves dividing the cylinder into sections and stretching and repeating it along those sections.

## Key Characteristics
- Uses cylindrical meshes instead of quads
- Shares properties with ribbon trails
- Trails are created by dividing the cylinder into sections and stretching and repeating it along those sections

## Applications
Tube Trails can be used to create visually appealing particle effects in Godot game engine, such as smoke, fire, or other effects that require cylindrical meshes.
