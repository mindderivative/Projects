## Description
Transform functions refer to the functions in Godot that are used to transform nodes and viewports. They include the canvas transform, global canvas transform, stretch transform, and window transform. These functions are essential for positioning and scaling objects in a 2D space. They are commonly used in 2D game development for creating user interfaces and organizing scenes. The canvas transform is a transform that is applied to each CanvasItem node in a CanvasLayer. It is used to position and scale the nodes. Every CanvasItem node resides in a Canvas Layer, which has its own transform. The canvas transform is a transform that is applied to each CanvasItem node.
