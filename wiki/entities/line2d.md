# Line2D

## Basic Information
- Type: product
- Source: [[sources/2d-antialiasing_bf461b]]

## Description
Line2D is a 2D node in Godot that can draw lines and has an Antialiased property which can be enabled in the inspector to support antialiasing. It is one of the recommended methods for enabling antialiasing in 2D rendering in Godot.
