# preload

## Basic Information
- Type: product
- Source: [[sources/logic-preferences_e3d71c]]

## Description
Preload is a global method in GDScript used to load resources as early as possible. It allows resources to be loaded in advance, which can help to avoid loading resources while in the middle of performance-sensitive code.
