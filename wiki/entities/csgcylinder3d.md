# CSGCylinder3D

## Basic Information
- Type: other

## Description
CSGCylinder3D is a CSG node that represents a 3D cylinder. It has properties to adjust its dimensions and can be combined with other CSG nodes using boolean operations. It also supports creating a cone shape.
