## Description
Android editor is a native port of the Godot editor running entirely on Android devices. It allows developers to work on their projects directly on their mobile devices, providing a convenient way to develop games and applications on the go. Android is a mobile operating system developed by Google and the Open Handset Alliance, based on a modified version of the Linux kernel and designed primarily for touchscreen mobile devices such as smartphones and tablets. For now, the Godot XR editor is only available for Android XR devices. Mobile is a rendering technique that is not supported when using the VoxelGI global illumination technique.
