## Description
The Godot XR editor is an application that enables developers to create and edit XR (Extended Reality) content on Meta Quest devices. This editor is a port of the Godot editor specifically designed to run natively on Meta Quest hardware. By using the Godot XR editor, developers can work on XR projects directly on their Meta Quest platform, eliminating the need for a separate computer. The Meta Horizon Store is a digital distribution platform that hosts Godot XR editor app and other Meta Quest applications, from which developers can download and install the editor.
