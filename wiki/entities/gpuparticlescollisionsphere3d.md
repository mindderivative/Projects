# GPUParticlesCollisionSphere3D

## Description
GPUParticlesCollisionSphere3D is a collision node shaped like a solid sphere. The size of the sphere can be controlled using the Radius property. While box collision nodes don't have to be perfect cubes, sphere collision nodes will always be spheres. For particle collision to work, the particle's [visibility AABB](https://docs.godotengine.org/en/stable/tutorials/3d/particles/properties.html#doc-3d-particles-properties-draw) must overlap with the collider's AABB. For particle collision to work, the particle's [visibility AABB](https://docs.godotengine.org/en/stable/tutorials/3d/particles/properties.html#doc-3d-particles-properties-draw) must overlap with the collider's AABB. There are four of them: [GPUParticlesCollisionBox3D](https://docs.godotengine.org/en/stable/classes/class_gpuparticlescollisionbox3d.html#class-gpuparticlescollisionbox3D).
