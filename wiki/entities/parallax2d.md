# Parallax2D

## Basic Information
- Type: product
- Source: [[sources/2d-parallax_2978be]]

## Description
The Parallax2D node is a Godot Engine component that provides the parallax effect, simulating depth by moving textures at different speeds relative to the camera. It supports adding nodes that render things as children and has properties like scroll_scale and repeat_size to control the effect. [[entities/icon-svg|Godot]] provides the [Parallax2D](https://docs.godotengine.org/en/stable/classes/class_parallax2d.html#class-parallax2d) node to achieve this effect. — [[sources/2d-parallax_2978be]]
