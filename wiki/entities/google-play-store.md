## Description
The Google Play Store is an online store for Android applications operated by Google. It allows users to download and install various apps, including the Godot Android editor. The store serves as the primary means of distributing applications for the Android operating system, making it a vital component for developers working on Android projects. In order to support new Google Play requirements, Android now requires targeting .NET 9 when exporting C# projects to Android, other platforms continue to use .NET 8 as the minimum required version but newer versions are supported and encouraged.
