# Speed Scale

## Basic Information
- Type: other
- Source: [[sources/3d-particle-system-properties_a7abd5]]

## Description
The Speed Scale property of the Godot Particle System node allows for the slowing down or speeding up of the particle system. This applies to both the processing of the particle system's data and the rendering of the particles themselves. Setting the Speed Scale property to 0 will pause the particle system completely, while setting it to a value greater than 1 will make the particle system move faster.
