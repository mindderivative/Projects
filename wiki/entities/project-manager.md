# Create

## Basic Information
- Type: button
- Source: [[sources/using-the-project-manager_c43384]]

## Description
The Web editor is a preliminary web-based version of the Godot editor. It is built upon the Godot editor's codebase and provides an equivalent user experience in a web environment. There is a Web editor you can use to work on new or existing projects. If you run into performance issues on Firefox, try using a Chromium-based browser as these may perform better in WebGL applications. Git is a distributed version control system that is used by the Godot game engine for version control. However, version control in the editor requires a plugin for the specific VCS you're using. The Create button in the Godot Project Manager allows the user to create a new project.
