# 3D Particle System Creation - Summary

## Core Content
This tutorial provides a detailed guide on how to create a 3D particle system using the GPUParticles3D node in Godot. It covers the necessary properties such as the Process Material and Draw Passes to set up and visualize particles in the scene. The tutorial also explains how to create a ParticleProcessMaterial and define Draw Passes for rendering particle meshes. Finally, it discusses the properties of a particle system and how to control each particle's behavior.

## Key Entities
- [[entities/gpuparticlescollisionsphere3d|GPUParticles3D]]: A node used in Godot to create 3D particle effects.
- [[entities/process-material|ParticleProcessMaterial]]: A special material used for updating particle data and behavior on the GPU.
- [[entities/draw-passes|Draw Passes]]: A concept in Godot particle systems referring to the rendering of particle meshes through different passes.

## Key Concepts
- [[entities/particle-system|particle-system]]: A graphical effect used in 3D rendering to create various effects such as fire, water, smoke, and explosions.
- [[concepts/particle|Particle]]: A small graphical element used in particle systems to create various effects.
- [[concepts/particle-system-properties|Particle System Properties]]: Properties used to control the behavior and appearance of particles in a particle system.

## Main Points
- GPUParticles3D node is used to create 3D particle effects in Godot.
- ParticleProcessMaterial is a special material for updating particle data and behavior on the GPU.
- Draw Passes are used to render particle meshes through different passes.
- Particle System Properties allow developers to control each particle's behavior and create a wide range of particle effects.
