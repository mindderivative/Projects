## Core Content
This tutorial provides an introduction to global illumination, a technique used in 3D rendering engines to simulate realistic lighting in a scene. Global illumination uses both direct and indirect light to create a more accurate representation of how light behaves in the real world. The tutorial explains the different components of global illumination, such as indirect diffuse lighting and specular lighting. It also discusses various global illumination techniques available in Godot, including VoxelGI, SDFGI, LightmapGI, and ReflectionProbe, and provides a comparison of their performance, visuals, and real-time ability. The tutorial also offers guidance on choosing the appropriate global illumination technique based on the user's requirements. For more information, visit the [godot] and [global-illumination-techniques] pages.

## Main Points
- Global illumination is a technique used in 3D rendering engines to simulate realistic lighting in a scene.
- Global illumination uses both direct and indirect light to create a more accurate representation of how light behaves in the real world.
- Different global illumination techniques offer varying levels of accuracy to represent indirect diffuse lighting and specular lighting.
- VoxelGI is a global illumination technique available in Godot that uses a voxel-based approach to simulate realistic lighting in 3D scenes.
