# When to use scenes versus scripts - Summary

## Source
- Original file: [[sources/when-to-use-scenes-versus-scripts_209303|Scenes vs Scripts]]
- Ingested: 2026-06-30

## Core Content
This tutorial explains the difference between Godot's scenes and scripts, when to use one over the other, and how to make both accessible through the editor's creation dialog. [scenes], [scripts] are both ways to organize and define behavior in Godot. [scenes] are best used for defining how a class initializes, while [scripts] are best used for defining a class's behavior. [scripts] can be made accessible through the editor's creation dialog by registering them as custom types.
