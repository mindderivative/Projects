# Using the XR editor - Summary

## Source
- Original file: [[sources/using-the-xr-editor_b03953|Using the XR editor]]
- Ingested: 2026-06-30

## Core Content
In 2024, the Godot XR editor was introduced, providing a version of the Godot editor designed to run natively on XR devices. This allows for the creation, development, and export of 2D, 3D, and XR applications and games directly on the device. The app can be downloaded from the Google Play Store, Meta Horizon Store, or Godot download page. For now, the Godot XR editor is only available for Android XR devices and the following Meta Quest devices running Meta Horizon OS v69 or higher.
