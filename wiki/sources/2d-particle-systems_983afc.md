## Core Content
This tutorial covers the use of particle systems in Godot for creating 2D visual effects. It explains how to create and configure a [[entities/gpuparticlescollisionsphere3d|GPUParticles2D]] or [[concepts/2d-meshes|2d-meshes]] node, and how to set up a [[concepts/particle-process-material|ParticleProcessMaterial]] for controlling the appearance of the particles. The tutorial also covers using [[concepts/flipbook|flipbook textures]] for more complex effects, and explains various [[concepts/time-parameters|time and drawing parameters]] for controlling the behavior of the particle system.

## Main Points
- Particle systems are used to simulate complex physical effects in 2D.
- Godot provides two nodes for creating particle effects: GPUParticles2D and CPUParticles2D.
- ParticleProcessMaterial is used to control the appearance of particles.
- Flipbook textures can be used to create more complex effects.
- Time and drawing parameters can be used to control the behavior of the particle system.
