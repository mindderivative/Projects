# Managing Editor Features - Summary

## Source
- Original file: [[sources/managing-editor-features_1098cd|managing-editor-features_1098cd]]

## Core Content
The Godot editor provides a feature called "feature profiles" that allows users to manage and hide certain features. This tutorial explains how to create and share a feature profile, and how to use self-contained mode for Godot to put all editor configuration in the same folder as the editor binary.

## Main Points
- Godot has a built-in system called "feature profiles" to manage editor features
- Feature profiles can be used to hide major features and nodes from the editor
- Users can create and share feature profiles
- Self-contained mode puts all editor configuration in the same folder as the editor binary
