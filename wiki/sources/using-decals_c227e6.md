# Decals - 3D Effects - Summary

## Source
- Original file: [[concepts/using-decals|Using decals]]
- Ingested: 2026-06-30

## Core Content
Decals are a powerful tool for creating 3D effects in Godot. They project textures onto surfaces in real-time, allowing for the creation of static decoration and dynamic gameplay elements. Decals can be used for adding texture detail to scenes, such as dirt or patches on large surfaces, or for temporary or persistent gameplay effects like bullet impacts and explosion scorches. Decals can be created in the 3D editor and during gameplay, and can be made to fade over time using an AnimationPlayer node or a script. Real-time rendering is used to create decal effects in Godot, and decals can make use of physically-based rendering to provide similar properties to full-blown PBR materials.
