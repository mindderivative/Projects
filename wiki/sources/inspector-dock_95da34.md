## Core Content
The Inspector dock is a feature in Godot that lists all properties of an object, resource, or node. It updates the list of properties as you select different nodes from the Scene Tree dock or use the Open command from the FileSystem's context menu.

## Main Points
- The Inspector dock lists all properties of an object, resource, or node in Godot.
- The Inspector dock updates the list of properties as you select different nodes from the Scene Tree dock or use the Open command from the FileSystem's context menu.
- The search bar in the Inspector dock allows you to filter displayed properties.
