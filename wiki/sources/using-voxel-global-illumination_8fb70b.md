# Using Voxel Global Illumination - Summary

## Source
- Original file: [[sources/using-voxel-global-illumination_8fb70b|using-voxel-global-illumination_8fb70b]]
- Ingested: 2026-06-30

## Core Content
Voxel Global Illumination (VoxelGI) is a fully real-time global illumination technique that can be used for small to medium-scale 3D scenes in Godot game engine. It is highly demanding on the GPU and is best used when targeting dedicated graphics cards. VoxelGI is only supported when using the Forward+ rendering technique, not the Mobile or Compatibility renderers. Forward+ is a rendering technique that is only supported when using the VoxelGI global illumination technique. It is not supported with the Mobile or Compatibility renderers.
