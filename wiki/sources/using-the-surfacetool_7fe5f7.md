## Core Content
The [SurfaceTool](https://docs.godotengine.org/en/stable/classes/class_surfacetool.html#class-surfacetool) is a utility class in Godot for constructing geometry. It provides an interface similar to the [ImmediateMesh](https://docs.godotengine.org/en/stable/classes/class_immediatemesh.html#class-immediatemesh) class, allowing the setting of per-vertex attributes such as normal, UV, and color. The SurfaceTool also offers helper functions like `index()` and `generate_normals()` to assist in the geometry construction process.
