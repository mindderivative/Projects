# Using the Android editor - Summary

- Original file: [[using-the-android-editor_0871e7|Using the Android editor]]
- Ingested: 2026-06-30

## Core Content
In 2023, Godot released an Android port of their editor, allowing developers to create, develop, and export 2D and 3D projects on Android devices. The editor requires devices running Android 5 Lollipop or higher with at least OpenGL 3 support. It also requires certain runtime permissions such as "All files access permission" and "REQUEST_INSTALL_PACKAGES". The app can be downloaded from the Godot download page or the Google Play Store.

## Main Points
- The Android editor requires devices running Android 5 Lollipop or higher, with at least OpenGL 3 support.
- The Android editor requires the 'All files access permission' to create, import, and read project files from any file locations on the device.
- The Android editor requires the 'REQUEST_INSTALL_PACKAGES' permission to allow the installation of exported projects directly from the editor.
- The Android editor requires the 'RECORD_AUDIO' permission to allow the recording of in-game audio for export.
- The app can be downloaded from the Godot download page or the Google Play Store.
