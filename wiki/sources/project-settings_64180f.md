# Project Settings - Summary

## Source
- Original file: [[concepts/emitter-properties|emitter-properties]]
- Ingested: 2026-06-30

## Core Content
The Project Settings window in Godot Engine allows developers to change various settings related to physics, rendering, and windowing. These settings can be modified from the editor, code, or by manually editing the project.godot file. Godot stores project settings in a project.godot file, which is a plain text file in INI format.
