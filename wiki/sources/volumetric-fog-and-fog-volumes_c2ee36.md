# Volumetric Fog and Fog Volumes Summary

## Source

## Core Content
This tutorial describes how to set up volumetric fog and fog volumes in Godot, a 3D game engine. Volumetric fog can be customized using Fog shaders and FogMaterial properties, including density, albedo, and emission. Fog volumes can be used to create local volumetric fog effects or to subtract fog from global volumetric fog. Quads can also be used as an alternative to volumetric fog for certain effects.

## Main Points
- Volumetric fog is a type of fog in Godot that can interact with lighting and can be customized using Fog shaders and FogMaterial properties.
- Fog volumes are a way to create local volumetric fog effects or to subtract fog from global volumetric fog in Godot.
- Quads can be used as an alternative to volumetric fog for certain effects in Godot.
