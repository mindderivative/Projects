## Main Points
- Godot provides several types of trails that can be added to a particle system.
- Before working with trails, a couple of parameters need to be set up, including creating a new particle system and assigning a process material.
- The simplest type of particle trail is the ribbon trail, which uses a quad divided into sections and stretched and repeated along those sections.
- Tube trails share properties with ribbon trails but emit cylindrical meshes instead of quads.
- Particle trails are only supported in the Forward+ and Mobile renderers, not Compatibility.
