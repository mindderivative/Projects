# Using the Project Manager - Summary

## Source
- Original file: [[sources/using-the-project-manager_c43384|using-the-project-manager_c43384]]
- Ingested: 2026-06-30

## Core Content
The Project Manager is the first window you see when you launch Godot. It allows you to create, remove, import, or play game projects. You can create a new project by clicking the Create button or open and import existing projects using the Import button. Projects can be managed with tags using the Manage Tags button.
