## Core Content
This tutorial provides an overview of 2D character movement in Godot. It covers various movement methods such as 8-way movement, rotation + movement, rotation + movement (mouse), and click-and-move. The tutorial demonstrates how to implement these movements using classes like CharacterBody2D, Input, and Node2D. It also explains how to set up the Input Map in the Project Settings. The tutorial uses the Godot icon (icon.svg) as the texture for the Sprite2D in the 8-way movement example.
