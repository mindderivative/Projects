# Using the Web Editor - Summary

- Original file: [[sources/using-the-web-editor_99481c|using-the-web-editor_99481c]]
- Ingested: 2026-06-30

## Core Content
The Godot game engine provides a Web editor that allows users to work on new or existing projects in a web browser. The Web editor is a preliminary version of the Godot editor and requires support for WebAssembly's SharedArrayBuffer. It is not recommended for production work and has several limitations compared to the native version of Godot. These limitations include the absence of some features, compatibility issues, and browser restrictions. The Web editor only supports the Compatibility renderer due to the lack of stable ways to run Vulkan applications on the web. For more information on system requirements and supported web browsers, please refer to the System requirements page.
