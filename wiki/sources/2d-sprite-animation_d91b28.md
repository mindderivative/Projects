## Core Content
This tutorial provides a comprehensive guide on creating 2D sprite animations in Godot using both the AnimatedSprite2D class and the AnimationPlayer. It covers animating individual images, sprite sheets, and using the AnimationPlayer to control animations.

## Key Entities
- [[concepts/spriteframes|spriteframes]]: A class in Godot that allows users to create 2D animations from individual images or sprite sheets.
- [[entities/animationplayer|AnimationPlayer]]: A class in Godot that allows users to create and control animations.
- [[entities/surfacetool|Sprite2D]]: A node in Godot that represents a 2D sprite used to display images in a scene.
- [[entities/icon-svg|Godot]]: A game engine that provides tools for creating 2D and 3D games, including classes like AnimatedSprite2D and AnimationPlayer.

## Key Concepts
- [[entities/surfacetool|surfacetool]]: A 2D image or texture used in Godot to represent an object or character in a scene.

- [[concepts/spriteframes|SpriteFrames]]: A resource in Godot used for storing animation frames.

## Main Points
- AnimatedSprite2D and AnimationPlayer are classes in Godot used to create and control 2D animations.
