## Core Content
Some developers like using the command line extensively. Godot is designed to be friendly to them, so here are the steps for working entirely from the command line. Given the engine relies on almost no external libraries, initialization times are pretty fast, making it suitable for this workflow.

## Main Points
- Godot is designed to be friendly for developers who prefer to use the command line.
- Godot has fast initialization times due to its reliance on almost no external libraries.
- The project.godot file contains information about a Godot project and can be used with command line arguments to run the engine.
