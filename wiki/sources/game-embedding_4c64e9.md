# Game Embedding - Summary

## Source
- Original file: [[concepts/emission|emission]]
- Ingested: 2026-06-30

## Core Content
Godot is an open-source game engine that allows users to run games within the editor itself. Game embedding can be configured in three states: Floating window (default), Main window, and Disabled. The Floating window mode runs the game in a separate window with a Game bar at the top for adjusting settings and selecting nodes in the embedded game. The Main window mode integrates the game into the editor window, providing direct access to the game settings. The Disabled mode disables game embedding completely.
