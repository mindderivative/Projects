## Core Content
CSG stands for Constructive Solid Geometry, which is a tool that combines basic shapes or custom meshes to create more complex shapes. In Godot, CSG is mainly used for prototyping levels and creating complex shapes. The CSG nodes in Godot are mainly intended for prototyping.
