# Version Control Systems - Summary

## Source
- Original file: [[concepts/particle|particle]]
- Ingested: 2026-06-30

## Core Content
The source file discusses how Godot aims to be VCS-friendly and generate mostly readable and mergeable files. It also mentions that Godot supports the use of version control systems in the editor itself. However, version control in the editor requires a plugin for the specific VCS being used.

## Key Entities
- [[entities/icon-svg|Godot]]: A game engine developed by the Godot Engine community.
- [[entities/godot-engine-community|Godot Engine Community]]: A group of developers and contributors who work together to create and improve the Godot game engine.
- [[entities/project-manager|project-manager]]: A distributed version control system used by the Godot game engine for version control.

## Key Concepts
- [[sources/version-control-systems_acde2f|Version Control Systems - Summary]]: Tools that help developers track and manage changes to files and codebases over time, allowing multiple people to work on the same project simultaneously and providing a way to merge changes.

## Main Points
- Godot aims to be VCS-friendly and generate mostly readable and mergeable files.
- Godot supports the use of version control systems in the editor itself.
- Version control in the editor requires a plugin for the specific VCS being used.
