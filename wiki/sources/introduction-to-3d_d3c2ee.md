## Core Content
This tutorial provides an introduction to 3D in Godot, explaining how to create and manipulate 3D scenes, the main 3D workspace, the coordinate system, and how to create 3D content using Godot's tools and resources. It also covers the creation of 2D games in a 3D environment.

## Key Entities
- [[entities/icon-svg|Godot]]: A popular open-source game engine used for creating both 2D and 3D games.
- [[entities/node3d|Node3D]]: The base node for all 3D objects in Godot, used to create and manipulate 3D scenes.
- [[entities/camera3d|Camera3D]]: A node in Godot that represents a camera in a 3D scene.
- [[entities/worldenvironment|WorldEnvironment]]: A node in Godot that allows changing the background color, mode, and applying post-processing effects to a 3D scene.

## Key Concepts
- [[concepts/transform3d|Transform3D]]: A 3x4 matrix used to represent the position, rotation, and scale of objects in Godot.
- [[concepts/3d-text|3d-text]]: The environment in Godot where 3D scenes are edited.
- [[concepts/coordinate-system-in-3d|Coordinate System in 3D]]: The metric system used in Godot for 3D, with 1 unit equal to 1 meter.
- [[concepts/particle|particle]]: Tools in the 3D workspace to move, rotate, and scale objects.
- [[concepts/view-navigation-in-3d|View Navigation in 3D]]: Controls for adjusting the viewpoint or angle while viewing a scene.
- [[concepts/rendering3d|rendering3d]]: The process of converting 3D models and scenes into 2D images or videos.

## Main Points
- Godot is an open-source game engine that supports both 2D and 3D game development.
- The 3D workspace in Godot is similar to the 2D workspace, with some differences in how objects are manipulated.
- Godot provides tools for creating and manipulating 3D content, including lighting, cameras, and meshes.
- 2D games can be created in Godot using 3D objects and cameras, allowing for more advanced lighting and shadow effects.
